## 目錄

| # | 名稱 | 說明 |
|---|---|---|
| 1 | Line_生日提醒工具 | 讀取試算表中的生日清單，當天發送提醒 |
| 2 | Line_天氣提醒工具 | 定時發送天氣資訊 |
| 3 | YouTube_自動更新標題機器人 | 依照影片觀看數自動更新標題 |
| 4 | UptimeChecker_定期檢查網站狀態 | 定期檢查網站，異常時發送通知 |
| 5 | Line_事件提醒工具 | 依設定的時間發送事件提醒 |
| 6 | Line_ChatGPT | 串接 ChatGPT 的 LINE 機器人 |
| 7 | Line_每週提醒工具 | 依星期與時間發送每週例行提醒 |
| 8 | LineBot_發圖機器人 | 輸入關鍵字，從試算表查詢並回傳對應圖片 |

## 使用前注意

- Token、API Key 等機密資訊請放在「專案設定 → 指令碼屬性」，不要直接寫在程式碼裡（此專案為錯誤示範）。
- 專案時區請設成 `(GMT+08:00) 台北`，否則時間相關的判斷會出錯。
